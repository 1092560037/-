# 音乐剧副屏字幕 PPT 生成器

把音乐剧剧本（Word 或 PDF）自动拆成「一句一页」的副屏字幕，套用你自己的示例 PPT 样式，直接生成可以放映的 `.pptx` 文件。

- **单个 HTML 文件**：下载后双击，用浏览器打开就能用，不用安装，不用联网。
- **文件不出本机**：剧本、模板都只在你的浏览器里处理，不会上传到任何服务器。
- **三种模式**：英文剧本出中英双语字幕，中文剧本出中文字幕，韩中混合剧本出韩中双语字幕。

---

## 快速开始

1. 下载 [`音乐剧字幕PPT生成器.html`](./音乐剧字幕PPT生成器.html)，用 Chrome 或 Edge 打开。
2. 在页面顶部选择模式。
3. 选择**示例 PPT（模板）**和**剧本**。
4. 在表格里检查、修改字幕，右侧可以预览每一页。
5. 点右下角 **生成字幕 PPT**，下载生成的 `.pptx`。

> 推荐使用最新版 Chrome 或 Edge。Safari 和 Firefox 一般也能用，但没有完整测试。

## 三种模式

### 英文剧本 · 双语字幕

| 页面类型 | 样式 |
|---|---|
| 曲目名页 | 英文曲名加引号在上，中文曲名加书名号在下 |
| 单人字幕页 | 角色名（大写）＋ ♪ 英文 ♪ ＋ ♪ 中文 ♪ |
| 双人字幕页 | 两人同时唱：上方是左栏角色的中英文，下方是右栏角色的中英文 |

- 支持 **Word（.docx）** 和 **PDF**。
- 剧本里的中文要自己填：可以在表格里一格一格填，也可以在「批量粘贴中文」里一行一句粘进去。粘贴时会自动去掉 `[00:25.298]` 这类时间帧。
- 中文和英文错位时，用中文格子旁的 **↑ ↓** 只移动中文。
- 支持批量清空中文：可以清空全部，也可以只清空某一首。

### 中文剧本 · 中文字幕

| 页面类型 | 样式 |
|---|---|
| 场次页 | 如「第一场」，单独一页 |
| 曲目名页 | 中文曲名，自动加书名号 |
| 唱段 | 角色名 ＋ ♪ 歌词 ♪ |
| 念白 | 角色名 ＋ 台词，不加 ♪ |
| 旁白 | 只有文字，不显示角色名 |

- 支持 **Word（.docx）** 和 **PDF**。
- 长台词会按每页字数上限自动拆页，默认 16 字。拆分时优先在句号处断开，其次是逗号。
- 类型标签可以点击，在「唱 / 白 / 旁白」之间切换。

### 韩中剧本 · 韩中双语字幕

| 页面类型 | 样式 |
|---|---|
| 韩中双语页 | 和英文双语字幕相同：上面韩文，下面中文 |
| 仅中文页 | 只有中文的台词按中文单人页样式，不加 ♪ |
| 双人页 | 两栏并排的对唱 |
| 曲目名页 | 只有中文曲名时按中文样式显示 |

- 只支持 **Word（.docx）**。
- 类型标签可以点击，在「韩中 / 仅中文」之间切换。

## 所有模式通用的功能

- **⚠ 可能识别错的行**：比如没有角色名、像是被拆开的半句、混进了舞台提示、字数超长、对唱有一边是空的。鼠标停在 ⚠ 上能看到原因，检查过就点一下标成 ✓。「只看」里选「⚠ 可能有问题的」可以集中检查。
- **超长提示**：英文、韩文、中文都可以设每页字数上限，超出的会标红。
- **黑场页**：可以在每首歌结束后、换场时（中文模式）自动插入纯黑页，也可以在任意一页后手动插入。
- **查找和批量替换**：可以限定只在某种语言或角色名里查找。
- **预览**：点表格任意一行，右侧显示这一页的样子；「全屏逐页看」可以像放映一样用 ← → 翻页。
- **撤销**：几乎所有操作都能撤销（Ctrl+Z）。
- **保存进度**：编辑进度会自动存在浏览器里，三种模式分开保存。也可以「保存进度」导出成 `.json`，换电脑或交给别人接着改。

## 模板 PPT 怎么准备

工具不自带样式，所有字体、字号、颜色、位置和背景都来自你提供的示例 PPT。

| 模式 | 模板需要的页 |
|---|---|
| 英文 / 韩中 | 第 1 页曲目名页，第 2 页单人字幕页，第 3 页双人字幕页 |
| 中文 | 第 1 页曲目名页，第 2 页单人字幕页 |

模板里每个文本框写上示例文字，工具会根据这些文字判断每个框的用途：

- 以冒号结尾的短文字，如 `MONTAGU:`、`角色名：`，会被当作**角色名框**。
- 含中文的框是**中文字幕框**。
- 只有英文的框是**英文（或韩文）字幕框**。
- 字幕前后的 ♪ 格式（字体、颜色）也会沿用模板里写的样子。

中文模式下，如果模板里有英文框，生成时会自动去掉它，并把中文移到原来两行的中间。

## 剧本格式要求

工具是按排版规律来识别的，剧本越规整，识别越准。

### 英文剧本

- **曲目名**：加粗，字号比角色名大；也可以写成 `[MUSIC NO. 01 "TITLE"]` 这样的格式。
- **角色名**：单独一行，加粗，以冒号或句号结尾，如 `Valjean:`、`HERMES.`。
- **舞台提示**：斜体，或者用括号括起来。
- **对唱**：PDF 里两栏并排、标题是 `X (in counterpoint):` 的格式；Word 里用两列表格，第一行写两个角色名。

### 中文剧本

支持两种写法，工具会自动判断。

**居中排版**（常见于 PDF）：
- 念白靠左，写成 `角色名 台词`，中间用空格或 Tab 隔开，或者角色名单独加粗。
- 唱段居中：先单独一行 `角色：`，下面是歌词。
- 曲目名写成 `M01 曲名`；场次写成 `第一场`。
- 舞台提示以 `〔` 开头，或者用楷体。

**逐行排版**（全部靠左）：
- 每行写成 `角色：台词`，全角、半角冒号都可以。
- 曲目名写成 `《曲名》`；场次写成 `第一幕 地点`。
- 唱段里单独一行 `O:` 或 `合唱：` 表示接下来由这个角色唱；没写角色名的歌词沿用上一个演唱者。
- 整行括号是舞台提示；`（C: …）` 这种括号里带角色名的，算作插话。
- `钢琴旋律：`、`【cue】` 这类乐器和技术提示会自动跳过。

### 韩中剧本

- 中文翻译写在上一行，对应的韩文写在下一行。
- 下一行没有韩文的中文，算作「仅中文」台词。
- 换角色时写成 `角色：…`。
- 曲目名写成 `M05 曲名-演唱者`，生成时只保留曲名。
- 两三人同时唱、用大段空格排成几栏的部分会尽量拆成双人页，但这类排版通常不整齐，都会标 ⚠，请对照剧本检查。

## 常见问题

**Q：生成的 PPT 和预览不完全一样？**
预览是近似效果，字体按这台电脑上已安装的显示，换行位置可能和 PowerPoint、WPS 略有不同。以生成的 PPT 为准。

**Q：读不出 `.doc` 文件？**
只支持 `.docx`。请在 Word 里「另存为 .docx」后再选。

**Q：PDF 读出来是空的？**
扫描件（图片）读不了，需要能选中文字的 PDF。

**Q：英文剧本的两栏版面转成 PDF 后识别乱了？**
请直接用 Word 原文件，不要先转成 PDF。

**Q：换了一台电脑，之前的进度没了？**
进度只存在当前浏览器里。换电脑前先点「保存进度」导出 `.json`，到新电脑上再「载入进度」。

## 关于版权

本工具只是一个排版工具，**仓库里不包含任何剧本、歌词或译文**。

剧本、歌词和译文通常受版权保护。请只用你们**有权使用**的剧本和译文制作字幕，比如已取得演出授权的剧目、社团自己翻译并获得许可的译文，并遵守演出授权里关于字幕的规定。

上传到公开仓库时，请不要把剧本、歌词文件、生成的字幕 PPT 或包含歌词的进度 `.json` 一起提交。可以参考下面的 `.gitignore`：

```gitignore
*.pptx
*.docx
*.pdf
*.json
```
